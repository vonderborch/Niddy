# PageRegistrationGenerator

`Niddy.Avalonia.Generators` · Niddy.Avalonia.Generators (optional package) · [source](../../src/Niddy.Avalonia.Generators/PageRegistrationGenerator.cs)

A Roslyn incremental source generator that registers every [`[PageRegistration]`](../Niddy.Avalonia/PageSystem/PageRegistrationAttribute.md) page at compile time, with no reflection. Install the package and you're done. It brings in Niddy.Avalonia and needs no setup code.

```bash
dotnet add package Niddy.Avalonia.Generators
```

## What it generates

For each assembly that references Niddy.Avalonia and has registered pages (or references assemblies that do), it emits `Niddy.Generated.Pages_<AssemblyName>`, an [`IPageProvider`](../Niddy.Avalonia/PageSystem/PageRegistry.md). The provider is marked with an assembly-level `[PageProvider]` attribute, so `PageRegistry` finds it:

- **when the assembly loads**, including plugins loaded later with `Assembly.LoadFrom`, and
- **through references**: each provider also `Include`s the providers of the referenced assemblies it can see, so their pages are registered before those assemblies load.

```csharp
// <auto-generated/> (roughly)
[assembly: global::Niddy.Avalonia.PageSystem.PageProvider(typeof(global::Niddy.Generated.Pages_MyApp))]

namespace Niddy.Generated
{
    public sealed class Pages_MyApp : global::Niddy.Avalonia.PageSystem.IPageProvider
    {
        public void RegisterPages()
        {
            global::Niddy.Avalonia.PageSystem.PageRegistry.Include<global::Niddy.Generated.Pages_MyApp_Core>();
            global::Niddy.Avalonia.PageSystem.PageRegistry.Register<global::MyApp.HomePage>(
                factory: static () => new global::MyApp.HomePage(), displayName: "Home", keepAlive: false,
                parents: null, children: null, topLevel: null, icon: null, shortcut: "Primary+1");
        }
    }
}
```

`[PageIcon]` attributes become the `icon:` argument, and `Shortcut` is checked the way `PageShortcut.Parse` checks it at runtime.

## Requirements for a registered page

- It derives from `Niddy.Avalonia.PageSystem.Page` (NIDDY002).
- It isn't abstract or generic, isn't nested in a generic type, and isn't private or protected (nor nested in a private or protected type). It has a public or internal constructor whose parameters are all optional (NIDDY003). Pages that need constructor arguments are registered by hand with `PageRegistry.Register(() => new MyPage(services))`.
- Its parents and children are pages (NIDDY004) and don't form a cycle (NIDDY001).

See [Diagnostics](Diagnostics.md) for all the errors and warnings.

## Example

```csharp
[PageRegistration(DisplayName = "Home", Shortcut = "Primary+1")]
[PageIcon(Data = "M10,20V14H14V20H19V12H22L12,3L2,12H5V20H10Z")]
public partial class HomePage : Page<MainDataContext, HomePageDataContext> { … }

[PageRegistration(Parents = [typeof(SettingsPage)])]
public partial class GeneralSettingsPage : Page<MainDataContext, GeneralSettingsPageDataContext> { … }
```
